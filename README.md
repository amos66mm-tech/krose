# GiftRadar

面向西非礼品卡买卖市场的**情报系统**：先尽量多收公开材料，整理成可检索的原文 / 实体 / 主题，再让你从里面发现自己真正需要的数据。

价格看板仍然在，但它只是从原文里抽出来的**派生视图**，不再是系统的中心。你事先不必知道要盯价格、投诉还是新平台——把网撒开，搜索会告诉你。

## 它解决什么问题

上一版预先假定你需要「价格 / 活动 / 社媒」三张表。如果市场真正重要的信号是：

- 一个种子名单里没有的新买家（例如 FlashCards NG）
- Telegram 假汇率广播
- MoMo 日限额被误当成平台跑路
- 多家平台同时被投诉，其实是银行周末维护

那三张表都看不见。合格的情报系统先**归档原文**，再谈抽取。

## 现在怎么工作

```
宽网搜索（市场 / 社区 / 风险 / 新平台 / 行情 / 已知 App / 你自己加的网）
        ↓
   每一条命中整篇入库（去重、FTS 索引）
        ↓
   整理：摘要、类型、实体、标签、事实（有 LLM 更好，没有也能启发式）
        ↓
   发现：检索、实体页、主题、相关原文
        ↓
   派生：如果原文里真有回收价，再写入价格看板
```

没有 `EXA_API_KEY` 时，系统加载一批**多样化演示语料**（论坛投诉、诈骗广播、新平台、监管、支付通道），让你先把「搜索 → 发现」用起来。真实采集**不会**把演示文档写进库。

## 快速开始

### 后端

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

```bash
python run_agent.py                 # 全量宽网
python run_agent.py --scope rates   # 只跑行情网
python run_agent.py --country NG
```

### 前端

```bash
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 。开发时 `/api` 会代理到 `:8000`。

### 真实采集

| 变量 | 作用 |
| --- | --- |
| `EXA_API_KEY` | 有它就能把公开网页收进情报库 |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | 可选。用来写中文摘要、标实体；没有时走启发式整理，原文仍可搜 |
| `SEARCH_RESULTS_PER_WATCH` | 每张网一次拉多少条原文，默认 8 |

## 面板

- **情报库**：规模、材料类型、新发现实体、最新原文
- **检索**：全文 + 类型 / 网 / 标签
- **原文**：摘要、事实、实体、完整正文、相关篇目
- **实体**：平台 / 卡种 / 支付通道 / 地点；「发现」= 不在种子名单里
- **主题**：从原文打上的标签
- **价格看板**：派生视图
- **采集**：系统预置的宽网 + 你随时加的网（会持久化，下次定时任务还会跑）
